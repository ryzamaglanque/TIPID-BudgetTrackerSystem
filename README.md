# T.I.P.I.D Budget Tracker System

![Java](https://img.shields.io/badge/Java-Swing-orange)
![NetBeans](https://img.shields.io/badge/NetBeans-IDE-green)
![Ant](https://img.shields.io/badge/Build-Apache%20Ant-red)

**T.I.P.I.D** (*Tracking Income, Purchases, and Individual Daily expenses*) is a desktop-based personal budget tracker built with **Java Swing** that allows users to plan monthly budgets, record their expenses by category, and review their spending, while enabling administrators to monitor and manage user accounts efficiently.

## Features

* User account registration and log-in
* Account lockout after 3 failed log-in attempts
* Monthly budget allocation per category
* Transaction management (add, update, delete)
* Budget protection against overspending
* Dashboard with spending charts
* Spending history with search, sort, and filter
* Admin user monitoring (unblock and delete accounts)
* Role-based access (User and Admin)

## Technologies Used

* Java Swing
* Apache NetBeans
* Apache Ant

## Installation

1. Clone the repository

```
git clone https://github.com/ryzamaglanque/TIPID-BudgetTrackerSystem.git
```

2. Open the project in NetBeans
   * Open Apache NetBeans.
   * Go to File > Open Project and select the cloned folder.
3. Make sure the `Image` folder is inside `src` so the logos and icons load
4. Right-click `LogInForm.java` and choose Run File (or press Shift + F6)
5. Log in with a test account or create your own account
   * User: `Tipida` / `pass`
   * Admin: `Admin` / `password` (security hint: `Hello World!`)
